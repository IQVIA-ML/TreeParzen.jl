# TreeParzen.jl Documentation

TreeParzen.jl is a pure Julia hyperparameter optimiser based on the tree-structured Parzen estimator. Install it from the Julia REPL with `] add TreeParzen`.

## Guides

- [Getting started](usage.md): use `fmin`, define search spaces, and tune with the ask/tell API.
- [Hyperparameter spaces](hyperparams.md): reference for the `HP` distributions and choices.
- [Configuration](configuration.md): optimizer settings and defaults.
- [Differences from Hyperopt](hyperopt-comparison.md): supported features and limitations compared with the original project.
- [MLJ integration](examples/simple_mlj_demo/simple_mlj_demo.md): a complete tuning example.
- [Development](development.md): diagnostics and running the test suite.
