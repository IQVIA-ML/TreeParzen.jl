# TreeParzen.jl

[![Build status](https://github.com/IQVIA-ML/TreeParzen.jl/workflows/build/badge.svg)](https://github.com/IQVIA-ML/TreeParzen.jl/actions)
[![License](https://img.shields.io/badge/License-BSD%203--Clause-lime.svg?style=flat)](LICENCE)

TreeParzen.jl is a pure Julia port of Hyperopt for hyperparameter optimization using the tree-structured Parzen estimator. It is registered in the Julia General registry. See [how TreeParzen.jl differs from Hyperopt](docs/hyperopt-comparison.md).

## Installation

In the Julia REPL, press `]` to enter the package manager, then run:

```julia
add TreeParzen
```

## Documentation

See the [documentation site](https://iqvia-ml.github.io/TreeParzen.jl/) for usage, hyperparameter spaces, configuration, and MLJ integration.
